# Aethelgard — The Weaver's Mark

Interactive dark fantasy text RPG set in the sunless continent of Aethelgard.

**Live site:** [https://nifze.github.io/aethelgard/](https://nifze.github.io/aethelgard/)

## Premise

Five years ago the Eclipse of Shattered Iron extinguished the sun. You are Kaelen Vane, former Captain of the Obsidian Guard, falsely executed and resurrected by an entity known as The Weaver. A shifting void-mark on your arm grants power at the cost of Corruption.

## Features

- Atmospheric opening in the Sunken Vaults of Iron-Hold
- Choice-driven branching narrative
- Live status dashboard (Health, Corruption, Inventory, Factions, Quest)
- Persistent save via localStorage
- Custom action input (limited free-text support)
- Pure HTML/CSS/JS — no frameworks

## Enable GitHub Pages

1. Repo **Settings → Pages**
2. Source: Deploy from a branch
3. Branch `main`, folder `/ (root)`
4. Save

Then visit: https://nifze.github.io/aethelgard/

## Local

Open `index.html` in any modern browser.
